MAINTAINER GUIDE · VERSION 0.1.0

Publish page-review

The npm package is named page-review, with no organization or scope. It is MIT licensed. Publishing makes it publicly installable; these steps are for you to run when ready.

1. Check the package

Open a terminal in the page-review project directory and run:

npm ci
npm test
npm pack --dry-run

The package includes src/, skills/, examples/, the HTML guides, README, and license. It excludes tests, personal review files, local configuration, and logs. Dependencies are installed automatically by npm.

To try the exact package before publishing:

npm pack
npm install -g ./page-review-0.1.0.tgz
page-review help
page-review setup
page-review demo
page-review status --open

If upgrading a running copy, use page-review restart before setup. Wait for active agent runs to finish. Rerun setup after testing another installation location so agent tools point to your chosen installation.

2. Sign in and publish

Create an account at npmjs.com if needed. Use your own individual account; an organization is not required.

npm login
npm whoami
npm view page-review name version

If the final command returns E404, the name appears unclaimed. If it returns a package owned by someone else, choose another unscoped name and update the package metadata and installation instructions. Name availability can change until publication.

npm publish --access public

npm runs the tests before publishing. Follow npm’s sign-in and two-factor prompts. The package becomes public only after this command succeeds. See npm’s public package guide for account requirements.

3. Share the installation commands

Your colleague needs Node.js 20.12 or newer and, for automatic replies, their own signed-in Claude Code or Codex installation.

npm install -g page-review
page-review setup
page-review open ./report.html

They can run page-review demo before opening their own file and page-review guide for the readable HTML instructions.

Future releases

Update the version without automatically creating a Git commit or tag, test, then publish:

npm version patch --no-git-tag-version
npm test
npm publish --access public

Update versioned examples in this guide when preparing the next release. npm versions cannot be overwritten after publication. Users upgrade with:

npm install -g page-review@latest
page-review restart
page-review setup
