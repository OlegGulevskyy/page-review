Page review

Leave comment threads on a local HTML page or dev server. Select text and choose Comment, or Alt+click an element. An agent can answer questions and edit the page’s source.

Review completed work yourself

Agent replies leave threads open, even when the work is complete. Select the thread and click Resolve after reviewing the answer or changes. Resolved threads remain available in the Resolved and All tabs, and can be reopened.

Clicking a thread takes you to its highlighted text or element. Text selections use their actual position, including selections that start after whitespace or live inside a scrolling container.

Choose the provider, model, and effort

  1. Open Comments → Agent settings.
  2. Select Claude Code or Codex.
  3. Choose a Model and Effort. Choose Custom model… to enter a model ID or alias. Default uses the CLI’s configuration.
  4. Click Save. Settings apply to subsequent runs for every page on this site and persist across reloads. Active runs keep the settings they started with.

Claude model suggestions use CLI aliases. Codex model suggestions and supported effort levels come from its local cached catalog when available. Custom IDs must be supported by the selected CLI and your account.

Use defaults removes this site’s override and follows the global runner settings. Switching provider starts a new agent session with access to the existing comment thread. Resetting an explicit model or effort to Default also starts a new session so the old override is not retained.

Off disables automatic replies, including work still waiting to start. Webhook uses the configured webhook; its receiver controls the model and effort. The local CLI must already be installed and signed in.

Command line

page-review open ./report.html
page-review open http://localhost:3000/ --project ~/dev/app
page-review runner claude --model opus --effort high
page-review runner codex --model YOUR_MODEL_ID --effort high
page-review runner codex --model "" --effort ""
page-review list
page-review get THREAD_ID
page-review reply THREAD_ID "Completed the requested change."
page-review log THREAD_ID

The runner command changes global defaults. Site overrides take precedence. Agent replies cannot resolve threads; the legacy --resolve flag is ignored.

Storage and verification

Settings and site registrations live in ~/.page-review/db.json. Comments on served files live in .page-review.json beside those files. Agent logs live in ~/.page-review/runs/. PAGE_REVIEW_HOME and PAGE_REVIEW_PORT can isolate a test instance.

Run npm test for regressions covering manual resolution, configuration validation and persistence, provider switching, fresh and resumed CLI arguments, queued-work cancellation, and text-anchor scrolling.
